Create `/work/solution.py` that defines `is_valid_ipv4(text: str) -> bool`.

A valid address is four decimal numbers from 0 to 255 separated by single dots. Numbers have no
leading zeros (`"0"` is fine, `"01"` is not), no signs and no whitespace.

Raise `TypeError` if `text` is not a string.

Use only the Python standard library.
