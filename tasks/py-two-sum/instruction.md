Create `/work/solution.py` that defines `two_sum(numbers: list[int], target: int) -> list[int] | None`.

Find two different positions `i < j` such that `numbers[i] + numbers[j] == target`. If several
pairs exist return the one with the smallest `j`, and among those the smallest `i`, as `[i, j]`.
Return `None` when no pair exists. The same element may not be used twice.

Use only the Python standard library.
