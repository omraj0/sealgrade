Create `/work/solution.py` that defines `rotate_clockwise(matrix: list[list[int]]) -> list[list[int]]`.

Return a new matrix that is the input rotated 90 degrees clockwise. The input is rectangular
(every row has the same length) and may be empty, in which case return `[]`. Do not modify the input.

Raise `ValueError` if the rows have different lengths.

Use only the Python standard library.
