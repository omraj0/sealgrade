# Contributing

## Set up

```bash
python -m venv .venv && . .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
```

Docker must be running for the integration tests and for `sealgrade matrix`.

## Checks (all must pass)

```bash
ruff check . && ruff format --check .
mypy
pytest -m "not docker"       # fast, no Docker needed
pytest -m docker             # real containers: controls and every documented attack outcome
```

## Adding an attack

1. Create `corpus/<attack-id>/` (lower-case words joined by hyphens).
2. Write `attack.toml`:

   ```toml
   [attack]
   id = "my-attack"
   title = "One line"
   summary = "What it does and why it should work on a weak harness."
   classes = ["V3"]                      # from docs/TAXONOMY.md
   patterns = ["Short name of the pattern"]
   agent_script = "agent.sh"             # optional: what a hostile agent runs in its sandbox
   repeat = 1                            # >1 for timing-dependent attacks

   [files]                               # optional: files left in the agent's working directory
   "conftest.py" = "payload/conftest.py"

   [expected]                            # what you claim happens, per tier
   t0 = "exploit"
   t1 = "blocked"
   ```

3. Rules for a valid attack:
   - It must **not** solve the task. The success rule is "verdict says pass".
   - It must beat tier T0 (every attack documents `t0 = "exploit"`).
   - Shell payloads use Unix line endings.
   - Keep it small and readable; the payload is the documentation.
4. Run `sealgrade matrix --attacks my-attack --no-controls --check`. If your claim and the
   measurement disagree, fix the claim or the attack; do not loosen the check.
5. Add the attack to the table in `docs/TAXONOMY.md`.

## Adding a task

A task is a folder under `tasks/` with `task.toml`, `instruction.md`, `cases.jsonl` (generated by
`tools/gen_cases.py` from the oracle, seeded and deterministic), `oracle/` and `near_miss/`.
Tasks must be written from scratch and use only the standard library.

## Commits

Small, imperative messages ("Block symlinked artifacts in the archive firewall").
