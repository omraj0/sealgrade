# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-10-07

### Added
- **Runner tiers**: T0 naive, T1 typical, T2 compat (hardened pytest-in-a-container) and T3 strict
  (three containers, artifact firewall, type-strict data comparison, signed verdicts).
- **Exploit corpus**: 30 attacks (21 exploits, 9 boundary probes) mapped to the BenchJack V1 to V8 taxonomy, each
  with a documented expected outcome per tier.
- **Proof matrix**: attacks x tiers, regenerated by `sealgrade matrix` and asserted in CI.
- **Auditor** (`sealgrade audit`): 26 static rules, mutation scoring of the verifier, optional dynamic run of
  the corpus, SARIF / JSON / HTML output, Harbor and Terminal-Bench layout adapter, GitHub Action.
- 13 original sample tasks with deterministic, generated cases.
- Container policy audit: the effective configuration is read back and compared with the policy.
- Retries for transient Docker daemon errors on idempotent API calls.
- Documentation site (MkDocs): threat model, taxonomy, how-to guide, generated corpus and rule references, ADRs.

### Measured
- Exploits that worked: T0 21 of 21, T1 10, T2 5, T3 0.
- Controls: 156 of 156 (13 tasks x 3 controls x 4 tiers).
- Median grading time: 2.0 s (T0), 3.2 s (T1), 3.1 s (T2), 3.4 s (T3).
